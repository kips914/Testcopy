# MaDaDev RTS — Лаунчер

Независимый лаунчер для **MaDaDev RTS** (RTrainSim): **реальная установка
карт, сценариев и модов** — из архивов, папок и репозиториев-зеркал, с
**автоматическим подтягиванием всех дополнений и зависимостей** пакета,
контролем версий, обновлением и удалением.

![Python](https://img.shields.io/badge/Python-3.11%2B-28ff96?logo=python)
![Только стандартная библиотека](https://img.shields.io/badge/зависимости-нет-00f0ff)

## Возможности

| | |
|---|---|
| **Установка из архива** | настоящий `.zip` с модом/картой → распаковка в `ROUTES/`, `TRAINS/`, `GLOBAL/`, запись в реестр, удаление |
| **Установка из папки** | папка с игровой структурой → копирование в папку игры |
| **Репозитории-зеркала** | каталог `manifest.json` на HTTP-сервере или в общей папке; несколько зеркал с автоматическим фейловером |
| **Авто-дополнения** | при установке рекурсивно подтягиваются все `addons` и `depends` пакета |
| **Надёжность** | SHA-256 всех файлов репозитория, резум загрузки, повтор при битом архиве, кеш |
| **Обновления** | сверка версий с каталогом, обновление, удаление «своих» файлов |
| **Свой репозиторий** | `tools/make_repo.py` собирает из папки с модами полноценное зеркало |
| **Запуск игры** | находит `.exe` симулятора и запускает его; кнопка «Папка игры» |

Зависимостей нет — только стандартная библиотека Python и tkinter.

> **Честно про демо.** В лаунчере есть *демо-каталог-заглушка*
> (150+ пакетов из текстовых файлов) — исключительно для проверки
> интерфейса и пайплайна, **для игры он не годится**. По умолчанию он
> **выключен**; включается вручную в Настройках. Вся установка выше —
> настоящая: те же код распаковки, реестр и защита путей, что и у
> репозиториев.

## Три способа реальной установки

### 1. Из архива (.zip)

Вкладка **«Установленные» → «📥 Установить из архива…»** → выбираешь
скачанный мод/карту. Лаунчер:

* проверяет пути в архиве (защита от zip-slip и абсолютных путей);
* читает метаданные `mddl.json` из корня архива (если есть);
* распаковывает файлы **относительно папки игры**;
* записывает пакет в реестр — его можно обновить или удалить.

Если `mddl.json` нет — id и имя берутся из имени файла, а тип
(карта/сценарий/мод/дополнение) определяется по структуре файлов
(`ROUTES/…ACTIVITIES…` → сценарий, `ROUTES/…` → карта, `TRAINS/…` → мод).

### 2. Из папки

Вкладка **«Установленные» → «📁 Установить из папки…»** — то же самое,
только копируется дерево папки (удобно, когда мод уже распакован:
`ROUTES/…`, `TRAINS/…`, `GLOBAL/…`).

### 3. Из репозитория (зеркала)

Каталог с `manifest.json` и архивами пакетов на HTTP-сервере или в
общей папке → **Настройки → Зеркала → «+ Добавить»**. Дальше всё через
каталог: поиск, фильтры, авто-дополнения, обновления, «Установить всё».

Собрать репозиторий из своей папки с модами:

```bash
python tools/make_repo.py D:\my_mods D:\rts_repo
```

* каждая **подпапка** `my_mods\` — пакет (внутри игровая структура и
  необязательный `mddl.json`);
* каждый **`.zip`** в `my_mods\` — готовый пакет;
* на выходе — `D:\rts_repo\manifest.json` + `packages\*.zip` со
  SHA-256; эту папку (или её URL) и добавляешь как зеркало.

### Метаданные пакета (mddl.json)

Необязательный JSON в корне архива/папки:

```json
{
  "id": "route-pavlovsk",
  "name": "Павловск",
  "type": "map",
  "version": "1.2.0",
  "description": "Маршрут Павловск — Веймарн",
  "depends": ["base-assets"],
  "addons": ["scenario-pavlovsk-1", "sound-pavlovsk"]
}
```

`depends` — обязательные зависимости; `addons` — дополнения,
подтягиваемые автоматически (рекурсивно). Файл `mddl.json` в игру не
копируется — он только для лаунчера.

## Запуск

**Вариант A — exe (рекомендуется):** скачай
[`release/MaDaDevRTS-Launcher.exe`](../release/MaDaDevRTS-Launcher.exe)
(≈13 МБ, x86-64) из ветки или из **Actions → Artifacts** —
самодостаточный файл, Python не нужен.

**Вариант B — из исходников:** установи Python 3.11+ с
[python.org](https://www.python.org/downloads/windows/) (галочка
«Add python.exe to PATH») и запусти **`run.bat`** (или `python main.py`).

При первом старте каталог пуст — это нормально: добавь зеркало
(способ 3) либо сразу установи архив/папку (способы 1–2).

## Сборка .exe (standalone)

**Вариант 1 — на своём ПК (Windows):** запусти **`build_exe.bat`**.
Он поставит PyInstaller и создаст `dist\MaDaDevRTS-Launcher.exe`
(без консоли, с иконкой и версией в свойствах файла).

**Вариант 2 — через GitHub Actions:** **Actions → «Build launcher EXE»
→ Run workflow** → готовый exe в **Artifacts** (и в ветке `release/`).

Что учитывает сборка exe:

* настройки и `launcher_error.log` пишутся **рядом с exe**, а не во
  временный каталог (важно для onefile-режима PyInstaller);
* необработанные ошибки попадают в `launcher_error.log` и в окно
  с ошибкой — удобно, когда консоли нет;
* иконка окна — `assets/launcher.png`, иконка файла —
  `assets/launcher.ico`.

## Настройки

Во вкладке **«Настройки»**:

1. **Папка с игрой** — корень симулятора, куда ложатся `ROUTES/`,
   `TRAINS/`, `GLOBAL/` (например `D:\Microsoft Train Simulator`).
2. **Файл игры (.exe)** — можно указать вручную, если авто-поиск не
   нашёл.
3. **Зеркала репозитория** — адреса каталогов. Активное зеркало
   пробуется первым, при сбое — следующее:
   * локальная папка с `manifest.json`;
   * `file:///D:/repo`;
   * URL вида `https://host/repo`.
4. **Авто-дополнения** — галочка «Автоматически подтягивать все
   дополнения и зависимости» (по умолчанию включена).
5. **Демо-каталог-заглушка** — по умолчанию **выключена** (см. выше).

Настройки хранятся в `config.json` рядом с `main.py`/`exe`.

## Как работает установка из репозитория

```
Каталог → выбираешь карту/сценарий/мод
        → resolve(): рекурсивно добавляются depends + addons
        → скачивание с зеркала (резум + SHA-256, кеш в .mddl/cache)
        → распаковка в папку игры (защита от zip-slip)
        → запись в <папка игры>/.mddl/installed.json
```

* **Карты** → `ROUTES/...`, **моды** → `TRAINS/...`, системные файлы →
  `GLOBAL/...` — по структуре из самого архива.
* Повторная установка той же версии пропускается; другая версия сначала
  удаляет старые файлы пакета, потом ставит новые.
* Удаление чистит **только** файлы, записанные в реестре пакета.

## Формат манифеста (manifest.json)

```json
{
  "schema": 1,
  "name": "Мой репозиторий MaDaDev RTS",
  "packages": [
    {
      "id": "route-pavlovsk",
      "name": "Павловск",
      "type": "map",
      "version": "1.2.0",
      "file": "packages/route-pavlovsk-1.2.0.zip",
      "size": 104857600,
      "sha256": "…64 hex…",
      "description": "Маршрут",
      "depends": ["base-assets"],
      "addons": ["scenario-pavlovsk-1", "sound-pavlovsk"]
    }
  ]
}
```

* `type` — `map`, `scenario`, `mod`, `addon`, `base`, `bundle`.
* `depends` — обязательные зависимости, ставятся всегда.
* `addons` — дополнения пакета, подтягиваются автоматически
  (рекурсивно), если включена галочка в настройках.
* ZIP содержит файлы **относительно папки игры**.

## Структура проекта

```
madadev_launcher/
├── main.py            # GUI (tkinter): каталог, установка, настройки, журнал
├── run.bat            # запуск из исходников (Windows)
├── build_exe.bat      # сборка standalone .exe (PyInstaller)
├── version_info.txt   # версия и описание для ресурсов exe
├── assets/
│   ├── launcher.png   # иконка окна
│   └── launcher.ico   # иконка exe (16–256 px)
├── core/
│   ├── paths.py       # пути для исходников и onefile-exe
│   ├── config.py      # настройки (config.json)
│   ├── manifest.py    # манифест + резолв зависимостей/дополнений
│   ├── net.py         # зеркала, резум-загрузка, SHA-256, фейловер
│   ├── install.py     # установка (репозиторий/архив/папка), реестр
│   └── demo.py        # демо-заглушка (выключена по умолчанию)
├── tools/
│   └── make_repo.py   # сборка настоящего репозитория из папки с модами
├── tests/
│   ├── test_core.py        # тесты ядра: манифест, сеть, реальная установка
│   ├── test_gui_smoke.py   # смоук-тест окна на заглушке tkinter
│   └── fake_tkinter.py     # заглушка tkinter для headless-тестов
└── README.md
```

Сборку exe также гоняет CI: `.github/workflows/build-launcher.yml`
(тесты на Linux → PyInstaller на Windows → артефакт).

## Тесты

```bash
python3 tests/test_core.py       # ядро: зеркала, SHA-256, установка из

```

## Заметки

* Официальные серверы MaDaDev используют закрытый протокол с
  авторизацией и из песочницы/публичного доступа не документированы —
  лаунчер работает с **любым открытым репозиторием** по формату выше и
  с локальными архивами/папками. Свое зеркало делается за минуту
  через `tools/make_repo.py`.
* Игра — Windows-приложение; запуск `.exe` работает на Windows.
* Для ручной сборки exe: `pyinstaller --noconsole --onefile main.py`.
