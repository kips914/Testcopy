# MaDaDev RTS — Лаунчер

Независимый лаунчер для **MaDaDev RTS** (RTrainSim): сам скачивает
**карты, сценарии и моды** из репозитория-зеркала и **автоматически
подтягивает все дополнения и зависимости** пакетов, ставит их в папку
игры и запускает симулятор.

![Python](https://img.shields.io/badge/Python-3.11%2B-28ff96?logo=python)
![Только стандартная библиотека](https://img.shields.io/badge/зависимости-нет-00f0ff)

## Возможности

| | |
|---|---|
| **Каталог** | список всех пакетов репозитория: карты, сценарии, моды, дополнения, база, наборы; поиск и фильтр по типу |
| **Авто-дополнения** | при установке лаунчер рекурсивно подтягивает все `addons` и `depends` выбранного пакета |
| **Зеркала** | несколько зеркал репозитория (Москва / Европа / свой сервер) с автоматическим фейловером |
| **Надёжность** | резум загрузки, проверка SHA-256, повтор при битом файле, кеш скачанных архивов |
| **Обновления** | сверка установленных версий с каталогом, обновление и удаление пакетов |
| **Полная сборка** | кнопка «Установить всё» ставит весь каталог, включая все дополнения |
| **Запуск игры** | находит `.exe` симулятора и запускает его из папки игры |
| **Офлайн-демо** | встроенный демо-репозиторий, чтобы проверить лаунчер без интернета |

Зависимостей нет — только стандартная библиотека Python и tkinter.

## Запуск

1. Установи **Python 3.11+** с [python.org](https://www.python.org/downloads/windows/)
   (галочка «Add python.exe to PATH»).
2. Запусти **`run.bat`** (или `python main.py`).

При первом старте создаётся демо-каталог — его сразу можно ставить.
Чтобы работал контент MaDaDev, добавь своё зеркало во вкладке
**«Настройки»** (см. ниже).

## Настройки

Во вкладке **«Настройки»**:

1. **Папка с игрой** — корень симулятора, куда ложатся `ROUTES/`,
   `TRAINS/`, `GLOBAL/` (например `D:\Microsoft Train Simulator`).
2. **Зеркала репозитория** — список адресов, откуда качать.
   Активное зеркало пробуется первым, при сбое лаунчер переходит
   на следующее. Типы зеркал:
   * локальная папка, в которой лежит `manifest.json`;
   * `file:///D:/repo`;
   * URL вида `https://host/repo` (отсюда будет браться `manifest.json`
     и файлы пакетов).
3. **Авто-дополнения** — галочка «Автоматически подтягивать все
   дополнения и зависимости пакетов» (по умолчанию включена).
4. **Демо-каталог** — встроенное офлайн-зеркало для проверки работы.

Настраивается в файле `config.json` рядом с `main.py`
(создаётся автоматически).

## Как работает установка

```
Каталог → выбираешь карту/сценарий/мод
        → resolve(): к пакету рекурсивно добавляются depends + addons
        → скачивание с зеркала (резум + SHA-256, кеш в .mddl/cache)
        → распаковка в папку игры
        → запись в <папка игры>/.mddl/installed.json
```

* **Карты** кладутся в `ROUTES/...`, **моды** — в `TRAINS/...`,
  системные файлы — в `GLOBAL/...` — по структуре из самого архива.
* Повторная установка той же версии пропускается, другая версия
  сначала удаляет старые файлы, потом ставит новые.
* Удаление чистит только файлы, записанные в реестре пакета.

## Формат манифеста (manifest.json)

```json
{
  "schema": 1,
  "name": "Мой репозиторий MaDaDev RTS",
  "packages": [
    {
      "id": "route-pavlovsk",
      "name": "Павловск",
      "type": "map",
      "version": "1.2.0",
      "file": "packages/route-pavlovsk-1.2.0.zip",
      "size": 104857600,
      "sha256": "…64 hex…",
      "description": "Маршрут",
      "depends": ["base-assets"],
      "addons": ["scenario-pavlovsk-1", "sound-pavlovsk"]
    }
  ]
}
```

* `type` — `map` (карта), `scenario` (сценарий), `mod` (мод),
  `addon` (дополнение), `base` (база), `bundle` (набор).
* `depends` — обязательные зависимости, ставятся всегда.
* `addons` — дополнения пакета, **подтягиваются автоматически**
  (рекурсивно, вместе со своими `depends`/`addons`), если включена
  соответствующая галочка в настройках.
* ZIP-архив содержит файлы **относительно папки игры**:
  `ROUTES/...`, `TRAINS/...`, `GLOBAL/...`.

Чтобы подключить свой репозиторий: положи `manifest.json` и папку
`packages/` на любой HTTP-сервер или в общую папку и добавь адрес
в настройках лаунчера.

## Структура проекта

```
madadev_launcher/
├── main.py            # GUI (tkinter): каталог, установка, настройки, журнал
├── run.bat            # запуск на Windows
├── core/
│   ├── config.py      # настройки (config.json)
│   ├── manifest.py    # манифест + резолв зависимостей/дополнений
│   ├── net.py         # зеркала, резум-загрузка, SHA-256, фейловер
│   ├── install.py     # установка/удаление, реестр .mddl/installed.json
│   └── demo.py        # генератор встроенного демо-репозитория
├── tests/
│   ├── test_core.py        # 51 проверка ядра (манифест, сеть, установка)
│   ├── test_gui_smoke.py   # смоук-тест окна на заглушке tkinter
│   └── fake_tkinter.py     # заглушка tkinter для headless-тестов
└── README.md
```

## Тесты

```bash
python3 tests/test_core.py       # ядро: манифест, зеркала, SHA-256, установка
python3 tests/test_gui_smoke.py  # логика окна без дисплея
```

## Заметки

* Лаунчер не взаимодействует с авторизацией и серверами официального
  проекта MaDaDev — он работает с любым открытым репозиторием
  по формату `manifest.json` выше. Добавь адрес зеркала сам.
* Игра — Windows-приложение; запуск `.exe` работает на Windows.
* Для сборки в один `.exe`:
  `pyinstaller --noconsole --onefile main.py`.
