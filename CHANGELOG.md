# Что изменилось

## 2.0
**Режим агента.** Нейросеть выполняет многошаговые задачи через инструменты: файлы, браузер, память, команды ПК
(`agent.py`). Включается голосом или галочкой в трее; разовая задача — «агент …»; «стоп» прерывает.

**Файлы** (`agent_tools.py`). Раньше: правка одним совпадением и `.bak` рядом с файлом. Теперь: список папок, поиск,
чтение по строкам, точечная замена с проверкой уникальности, окончания строк Windows сохраняются, копии в
`data/backups` с откатом, автопроверка `.py`/`.json`, корзина для удаления, защита секретов.

**Браузер.** Весь Playwright в одном выделенном потоке (раньше падал при вызове из разных потоков), номера элементов
вместо угадывания селекторов, вкладки, постоянный профиль, закрыты localhost/домашняя сеть/`file://`, пароли и
оплата только с согласия. Исправлено: фраза «открой сайт.ру» раньше уходила в Playwright вместо обычного браузера.

**Память** (`memory_store.py`). Раньше у `Actions` и `LocalAI` были две копии, и они затирали записи друг друга; теперь одна
общая, файл перечитывается при изменении. Дубли фактов не плодятся, секреты вырезаются, есть поиск, дела и заметки.
Память подмешивается в подсказку и для Claude (раньше — только для локальной модели). История запросов ведётся для всех
команд, а не только для ответов нейросети.

**Ассеты.**
- Позы: удалены 5 дублей (`*_new_mirror` — точные зеркала и двойные зеркала, `каприии.png` — копия `capri_alt.png`);
  зеркальные версии названы `*_flip.png`. Было 11 файлов, стало 6 без повторов.
- Анимации: уникальные кадры + `anim.json` (порядок и fps). `capri` 60 → 5 файлов, `eyes` 32 → 8, `capri_reverse` 60 → 5,
  `capri_soft_loop` 30 → 5. Загрузка ленивая: «capri» и «eyes» сразу, остальные при первом показе
  (раньше 206 кадров считались в память при каждом запуске, хотя играли только две анимации).
  Старый формат (номерные PNG от `tools/convert_anim.py`) читается как раньше.
- Иконки: новые, из лица Капри, 16–256 px, квадратные и круглые + `capri.ico`. Старые были обрезанной позой с обводкой,
  нечитаемой в малых размерах.
- Из архива убраны `__pycache__` и ярлык `run — ярлык.lnk` (вёл на `D:\capricorn-main`).

**Исправлено в сборке.** `requirements-agent.txt` и раздел README про агента были испорчены литеральными `\n` — переписаны.
